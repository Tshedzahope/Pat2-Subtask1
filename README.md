#Overview of Morse Code

Morse code is a method of communication that uses a series of dots (.) and dashes (-) to represent letters, numbers, and punctuation. It was widely used in telecommunication before the invention of modern digital communication systems.

Each letter or number is represented by a unique combination of dots and dashes. For example:

* A = .-
* B = -…
* C = -.-.



#Historical Background

Morse code was developed in the 1830s and 1840s by Samuel Morse and Alfred Vail. It was originally created to be used with the telegraph, which allowed messages to be sent over long distances using electrical signals.

It became very important in:

* Military communication
* Maritime (ships at sea)
* Early radio communication

Even today, Morse code is still used in emergency signals like SOS (… — …).


#How Morse Code Works

Morse code works by using signals of different lengths:

* A dot (.) is a short signal
* A dash (-) is a longer signal

#Timing Rules:

* The space between dots and dashes in a letter is short
* The space between letters is slightly longer
* The space between words is even longer

#Example:

Word: HELLO

* H = ….
* E = .
* L = .-..
* L = .-..
* O = —

So, HELLO in Morse code:
…. . .-.. .-.. —
